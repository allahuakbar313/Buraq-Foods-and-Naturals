## Publish for free
The site is a static website and can be hosted on GitHub Pages at no hosting cost. Your Namecheap domain can be connected to the GitHub Pages site through DNS settings.

## Important
The Basmati Rice packaging shown is a design concept created from the requested Buraq branding direction. Before commercial printing, verify all package text, regulatory statements, net weight, ingredients, origin, nutrition facts, UPC/barcode, certifications and importer/distributor information as applicable.
